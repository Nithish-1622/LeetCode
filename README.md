# LeetCode Solutions


This repository contains my personal collection of solutions to LeetCode problems, written primarily in C++. The goal is to practice and improve problem-solving skills for coding interviews and competitive programming.

## Repository Structure

Each problem has its own dedicated directory, named in the format `XXXX-problem-name`, where `XXXX` is the LeetCode problem number. Inside each directory, you will find:

*   `README.md`: The original problem description from LeetCode.
*   Solution file(s): One or more source code files (e.g., `problem-name.cpp`) with the implemented solution.
